# Hardware
Hardware can be identified by the product ID (PID), which consists of `FFI` for Client devices and the number of inputs followed by the number of outputs. The suffix of the PID indicates the two-digit year and two-digit month of the design release. All single-digit values have a leading zero. For example, a device with PID FFI0600-2011 is a FireFly Client with 6 inputs, 0 outputs, with a final design dated November 2020.

Hardware is also designated a hex code, which is a hexadecimal representation of the numeric portion of the PID. For example, FFI0600-2011 has a hex code of `0x06002011`.
